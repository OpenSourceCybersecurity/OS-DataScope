Status of each V1 acceptance criterion in `05-ACCEPTANCE-TESTS.md`. As that document requires, nothing here is called production-ready on unit tests alone.

The Windows lab checks listed still need recording for a domain.

Environments: Linux CI is Ubuntu with PostgreSQL 16 and a throwaway Samba AD domain controller; Windows CI (on main and on runs started by hand, D150) is the current GitHub Windows Server image with PostgreSQL 17, local accounts and a local share, not joined to a domain.

## Before a production deployment

Beyond the lab run, these are not code and need whoever ships a build:

- A code signing certificate (W36) and the security contact address in `SECURITY.md`.
- A privacy notice for your organisation. `SECURITY.md` ("What Data Scope does with data") and `DETECTION-LIMITATIONS.md` are the factual inputs.
- An external security review or penetration test of the installed product (M5c plan).
