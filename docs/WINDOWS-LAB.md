# Windows lab checks (UNVERIFIED until run)

These checks need a real Windows domain. They have **not** been run yet. Until someone runs them and records the results below, treat the matching features as UNVERIFIED.

## Lab

- **Domain controller:** your test domain. Steps below write it as `yourdomain.local` (short name `YOURDOMAIN`); use your own names. Use test users only.
- **File server `fs01`:** Windows Server 2022 or 2025, joined to the domain.
- **Data Scope server `ds01`:** install it with `docs/INSTALL-DATASCOPE.md`.
- **Scan identity:** a gMSA or plain service account, for example `YOURDOMAIN\svc-datascope`. It is **not** a member of any admin group.

## Set up shares on fs01 (PowerShell, as admin)

```powershell
New-Item -ItemType Directory C:\Shares\HR\Payroll, C:\Shares\HR\Restricted, C:\Shares\Finance, C:\Shares\Operations\Projects -Force
"synthetic" | Set-Content C:\Shares\HR\Payroll\march.xlsx
"synthetic" | Set-Content C:\Shares\HR\Restricted\secret.txt
New-SmbShare -Name HR -Path C:\Shares\HR -ReadAccess "YOURDOMAIN\svc-datascope"
New-SmbShare -Name Finance -Path C:\Shares\Finance -ReadAccess "YOURDOMAIN\svc-datascope"
New-SmbShare -Name Operations -Path C:\Shares\Operations -ReadAccess "YOURDOMAIN\svc-datascope"
# Deny the scan account on one folder
icacls C:\Shares\HR\Restricted /deny "YOURDOMAIN\svc-datascope:(OI)(CI)(RX)"
# A junction loop
cmd /c mklink /J C:\Shares\Operations\Projects\loop C:\Shares\Operations
# Synthetic sensitive data for the M2 checks (made-up values only)
"Name,SSN`r`nAvery Okafor,512-48-3307" | Set-Content C:\Shares\HR\Payroll\march.csv
"Card on file 4111 1111 1111 1111" | Set-Content C:\Shares\Finance\cards.txt
"Part# 512-48-3307 on back order" | Set-Content C:\Shares\Operations\Projects\notes.txt
# An offline (stub) file: must not be read or recalled
"synthetic" | Set-Content C:\Shares\Finance\archived.txt
attrib +O C:\Shares\Finance\archived.txt
# Permission cases for the M3 checks (test groups only)
New-ADGroup HR_Readers -GroupScope Global -Path (Get-ADDomain).UsersContainer   # run on dc01, or with RSAT
icacls C:\Shares\HR /grant "YOURDOMAIN\HR_Readers:(OI)(CI)RX"
New-Item -ItemType Directory C:\Shares\HR\Benefits -Force
"Name,SSN`r`nRiley Tanaka,512-48-3308" | Set-Content C:\Shares\HR\Benefits\fmla.csv
icacls C:\Shares\HR\Benefits /grant "Everyone:(OI)(CI)RX"
icacls C:\Shares\Finance /inheritance:r /grant:r "Administrators:(OI)(CI)F" "YOURDOMAIN\svc-datascope:(OI)(CI)RX"
```
